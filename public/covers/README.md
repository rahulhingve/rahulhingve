# cover art goes here

Drop the cover images for your top-5 songs here. Square images look best (1:1 ratio, e.g. 600x600).

Default filenames expected:
- song1.jpg
- song2.jpg
- song3.jpg
- song4.jpg
- song5.jpg

You can use .jpg, .png, or .webp — just update the `cover` field in `src/data.js` if you change the extension.
